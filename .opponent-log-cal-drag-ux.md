## Goal

Improve the visual + experiential quality of owner-only drag-to-reschedule
in the weekly calendar grid. Today: drag works correctly but the block
stays static during drag (no live tracking, no snap preview, no drop
indicator, no cursor state). Result: feels broken even when it's working.

## Slice (TDD-friendly, one task per cycle)

1. **Live transform during drag.** EventBlock applies `translate3d(0, dy, 0)`
   while the user is moving. Block follows the cursor.
   - Pure logic: a `getDragDeltaPx(startY, currentY)` helper, unit-tested.
   - Wiring: WeeklyGrid keeps live `dragDeltaPx` state (throttled with rAF
     to avoid React re-render storms).
   - Pass to DayColumn → EventBlock so only the dragging block transforms.

2. **Snap preview to 15-min grid.** While dragging, snap the live transform
   to the nearest 15-min slot offset (using existing `pxToMinutesSnapped`
   from `drag-reschedule.ts`). User sees discrete 15-min jumps, not raw px.
   - Reuse existing snap math; add `snapDeltaPxToGrid(dy, hourHeights, snap)`.

3. **Cursor states.** Owner blocks: `cursor: grab`. While dragging:
   `cursor: grabbing` on `<body>` (so it stays consistent over any element
   the pointer moves over). Non-owners: `cursor: pointer` (open popover).

4. **Visual elevation while dragging.** Add a `data-dragging="true"` state
   on the block; elevate via shadow + slight scale (1.02) + opacity 0.95.
   No layout shift — pure transform.

5. **Floating time tooltip.** Small floating label near the dragged block
   showing the proposed new start time (formatted in viewer TZ). Positions
   itself relative to the current pointer Y so it never gets clipped.

6. **Smooth release.** When the user releases, animate the block from its
   live transform position into its final snapped position (CSS transition
   on `transform` for ~150ms). On a no-op drop, animate back to origin.

7. **Touch friendliness.** Verify pointer events work on touch (the spec
   already uses Pointer Events API which covers this). On `pointerdown`,
   call `setPointerCapture` so a fast finger drag doesn't lose the pointer.
   Also `touch-action: none` on owner blocks to disable scroll-on-drag on
   mobile.
