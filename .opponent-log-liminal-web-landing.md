## The 8 moves (acceptance criteria)

1. **Kill SaaS hero.** Replace `Calendar/Link2/Users` lucide feature grid + "Get started" CTA with: a single SVG hand-drawn-style illustration (seasonal wheel or marginalia-doodled calendar — inline SVG, no external assets) + one short serif sentence. No "Get started free." button.
2. **Warm serif body, mono for metadata.** Add a serif font stack utility (system fallback ok: `font-family: 'Iowan Old Style', 'Palatino Linotype', Palatino, Georgia, serif`). Use mono (`font-mono`) only for dates, IDs, slugs, footnote markers.
3. **Tufte-style sidenote column.** Layout = essay column with right-margin notes on `md:` and up; sidenotes collapse to inline italic glosses on mobile. Glossed terms: RSVP, host, Hylo, recurring ritual, handle, coliving. Implement as a `<Sidenote>` component.
4. **Real upcoming events as essay entries.** Query the same public events the home page already fetches (mirror the `publicOnlyEventsCondition` path from `src/app/page.tsx`). Render top 3–5 as essay paragraphs with a hand-drawn marginal icon (inline SVG, vary per event), a "planted N days ago" stamp, and a lifecycle badge (proposed 🌱 / confirmed 🌿 / past 🍂). If no events, render a single "the calendar is quiet this week" essay paragraph — no empty grid.
5. **Hand-drawn map of gathering places.** Inline SVG sketch with annotated pins for the named coliving sites referenced in the codebase (don't invent — grep for actual venue/location strings; if none, render a generic seasonal-wheel map with months as pins). Replace the "features" grid section entirely.
6. **Honest lifecycle labels.** The 🌱/🌿/🍂 emoji + word badge is visible on every event entry. Derive from `event.startsAt` (past/upcoming) and an optional `status` if present in schema — check `src/lib/db/schema.ts` for what's there before inventing.
7. **Colophon, not footer.** Replace the `<footer>` with a `<aside class="colophon">` listing: fonts in use, illustration credit ("illustrations: hand-drawn, in-tree SVG"), maintainers (read from `package.json` author/contributors if present; else "Liminal Commons"), source repo link (`https://github.com/liminalcommons/liminal-calendar` if that's the real URL — check submodule `git remote -v`), and a one-line ethos quote.
8. **Strip every SaaS tell.** No "Sign in" pill button in the header — replace with a quiet inline text link `Sign in with Hylo →` in body serif, placed in a natural sentence in the hero paragraph AND once near the colophon. No feature grid, no testimonials, no "trusted by," no gradient. Header `bg-grove-bg` only.
